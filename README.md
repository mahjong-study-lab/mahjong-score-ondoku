# 麻雀点数 即答練習

麻雀の牌姿と役・あがり方を見て、点数をすぐ声に出すためのブラウザ練習アプリです。

[アプリを開く](https://mahjong-study-lab.github.io/mahjong-score-ondoku/)

## 使い方

1. ステージとレッスンを選ぶ。
2. 牌姿を見て点数を声に出す。符だけを答えるレッスンでは符を答える。
3. 必要なときだけ「符のヒント」「符を見る」「点数表を見る」を使う。
4. 「答えを見る」で確認し、次の問題へ進む。

スマートフォンとパソコンのどちらからでも利用できます。現在はオンライン利用のみで、オフライン利用には対応していません。

全ステージの問題は牌姿から答える形式です。役名は表示し、あがり牌・副露・暗槓は手牌から分けます。

点数・符は [Mリーグ公式ルール](https://m-league.jp/about/) に合わせています（切り上げ満貫あり、連風牌の雀頭は2符）。現在の範囲では、60符3翻のロンは子8,000点・親12,000点です。対局全体のルールを扱うアプリではありません。

40符まで総合チェックでは、間違えた問題だけを端末内でPDFにできます。作成後は「PDFをダウンロード」から保存します。対応端末では「別の方法で保存」も使え、iPhoneの共有メニューから「ファイルに保存」を選べます。ダウンロードできない場合は「PDFを開く」から保存してください。

## データの取り扱い

このアプリは、回答・進捗などの入力、保存、外部送信を行いません。アクセス解析も使用していません。
